# Самоуправление 2026
 
Сайт для Недели самоуправления 2026 в Усть-Илимском Экспериментальном лицее имени М.М. Батербиева.
 
Сайт: https://samoupravlenie2026.ru
 
## Что умеет сайт
 
- **Вход по логину и паролю.** Каждый ученик заходит в свой кабинет.
- **Рейтинги.** Топ групп и топ учеников по трём параллелям: РВГ (5–6 классы), ППГ (7–9) и профили (10–11).
- **О нас.** Карточки команды с описанием каждого участника.
- **Магазин.** Ученики тратят renocoins на товары.
- **Профиль.** Статус на неделе, баланс renocoins, соцрейтинг (только у дублёров), список покупок, история начислений и списаний, жалобы на дублёра, смена пароля.
- **Панель дублёра.** Начисление renocoins за дела (сумму определяет сервер) и списание за нарушения.
- **Админ-панель.** Соцрейтинг дублёров, все логи renocoins, все покупки и все жалобы.
- **Жалобы на дублёров.** Ученик выбирает дублёра и описывает ситуацию.

## Запуск локально
 
Нужен Python 3.10+ и PostgreSQL.
 
```bash
git clone https://github.com/nikita1v2/samoupravlenie2026.git
cd samoupravlenie2026
 
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
 
Задайте переменные окружения (см. ниже) и запустите приложение:
 
```bash
# для разработки
flask --app app run --debug
 
# как на сервере
gunicorn app:app
```
 
Фронтенд статический: файлы из `frontend/` отдаются любым веб-сервером (nginx, `python -m http.server` и т.п.). Адрес API прописан в `frontend/script.js`, при локальной разработке поменяйте его на свой.
 
## Переменные окружения
 
| Переменная | Назначение |
|------------|------------|
| `DATABASE_PATH` | Путь или строка подключения к базе данных. Используется в `app.py` и в `hash_existing_passwords.py` |
 
Другие переменные (секретный ключ и т.п.) смотрите в `app.py`.
 
## Пароли
 
Пароли в базе хранятся в виде хешей (`werkzeug.security`). Если в базе остались пароли открытым текстом, один раз запустите скрипт рядом с `app.py` на той машине, где лежит база:
 
```bash
python hash_existing_passwords.py
```
 
Уже захешированные пароли скрипт пропускает, поэтому повторный запуск безопасен.
